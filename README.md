### Jelajah Jogja
Jelajah Jogja adalah aplikasi web berbasis GPS yang membantu pengguna menemukan dan menjelajahi berbagai tempat wisata serta kuliner di Daerah Istimewa Yogyakarta.

Aplikasi ini memanfatkan lokasi perangkat untuk menampilkan rekomendasi tempat terdekat, menyediakan informasi jarak dan estimasi waktu perjalanan, serta membantu pengguna menentukan rute menuju lokasi tujuan.

### Fitur Utama
- Deteksi lokasi pengguna menggunakan GPS.
- Rekomendasi tempat wisata dan kuliner terdekat.
- Peta interaktif menggunakan Leaflet dan OpenStreetMap.
- Pencarian dan filter lokasi.
- Perencanaan rute berdasarkan moda transportasi.
- Navigasi menuju lokasi tujuan.

### Instalasi
1. Clone atau download repository ini.
2. Simpan folder proyek ke direktori htdocs XAMPP.
3. Jalankan Apache dan MySQL melalui XAMPP.
4. Import file database.sql melalui phpMyAdmin.
5. Sesuaikan konfigurasi database pada config/database.php.
6. Buka aplikasi melalui browser dengan alamat http://localhost/nama-folder-proyek.

### Catatan
Aplikasi membutuhkan koneksi internet dan izin akses lokasi perangkat agar fitur GPS, peta, rekomendasi, dan perhitungan rute dapat berjalan dengan baik.
